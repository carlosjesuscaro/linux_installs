# Notes
- Fonts
  - Fonts to be installed from https://www.nerdfonts.com/
    - Download JetBrainsMono zip folder
    - Install these:
      - JetBrainsMono Nerd Font **Mono** Regular.ttf 
      - JetBrainsMono Nerd Font **Mono** Bold.ttf 
      - JetBrainsMono Nerd Font **Mono** Italic.ttf 
      - JetBrainsMono Nerd Font **Mono** BoldItalic.ttf
  - Configure Konsole Profile to use the new font
- PowerLevel10K installation
- Install Go so that lazygit can be installed
